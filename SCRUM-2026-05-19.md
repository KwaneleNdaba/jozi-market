### 3. MongoDB Waitlist User Model

**File:** `lib/models/WaitlistUser.ts`

- Mongoose schema with fields: `name`, `email` (unique, lowercase), `phone`, `type` (buyer | vendor), `ipAddress`.
- Indexes: `email` (unique), `type`, `createdAt` (descending).
- Timestamps via `{ timestamps: true }`.
- Collection: `waitlist_users`.

---

### 4. Waitlist Server Actions

**File:** `app/actions/waitlist/index.ts`

- `registerWaitlistAction(input)`: Validates input, checks for duplicate email, creates document in MongoDB, returns typed response.
- `getWaitlistCountAction()`: Returns total waitlist count (used to show social proof on landing page).
- Both functions use `dbConnect()` from `lib/mongodb.ts` (existing connection utility).
